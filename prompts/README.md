# Generation Prompts

This directory stores public, reproducible prompt text and parameter notes only.

- [`h3-scene.md`](h3-scene.md): master scene video.
- [`speech.md`](speech.md): mission and state voice lines.
- [`music.md`](music.md): restrained background music and sound-design experiments.

Generated media, provider responses, subscription details, IDs, and API keys are intentionally excluded from this repository.
