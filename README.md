# H3 2.5D 狙击挑战

一个由 MiniMax Code 构建、以 H3 动态场景为可玩空间的桌面浏览器狙击挑战。

玩家先在完整场景中观察和移动准星，开镜后自动进入准星所在的局部视野。在位置暴露前找到隐藏目标并完成射击，否则会被对方抢先发现。

## 当前状态

正在 Build in Public。代码、生成提示词和复现说明会保留在本仓库；H3 视频、语音、音乐、截图、录屏和任何 API Key 不进入公开 Git 历史。

## 计划体验

- 开始与场景选择；
- 完整动态场景观察；
- 按准星位置进入局部瞄准镜；
- 隐藏时限、环境危险提示、命中与被击中；
- H3 环境声、MiniMax 任务语音、音乐与交互音效；
- 电脑端鼠标和键盘操作；
- 一键重玩。

## 本地开发

正式代码建立后更新。任何本地 MiniMax 配置只进入被忽略的 `.env.local`，公开示例文件只保留空变量名。

## 生成提示词

见 [`prompts/`](prompts/README.md)。公开仓库只保存提示词和参数记录，不分发生成视频与音频。
